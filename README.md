# 🚀 AgileFusion – Hybrid Project Management SaaS Platform

AgileFusion is a full-stack project management system inspired by **Jira, Microsoft Project, and Trello**.  
It combines Agile sprint tracking, Kanban workflow management, Gantt visualization, and analytics into one unified SaaS-style platform.

## 📌 Project Objective

The goal of this project was to analyze three widely used industry tools and integrate their best features into a single, clean, and professional interface.

### 🔧 Selected Industry Tools:
- **Jira** – Sprint management, issue tracking, analytics dashboard
- **Microsoft Project** – Gantt chart and structured timeline planning
- **Trello** – Kanban board with drag-and-drop task management

AgileFusion merges these functionalities into a hybrid project management system.

### 👥 Team Management

↓
